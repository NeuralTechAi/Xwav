# Xwav skills

Xwav bundles **39 native skills**. The entries below link to their canonical instructions; this file is an index, not a second copy of the skills.

In a job, describe your task and the agent selects skills only when their instructions materially help that request. Short names/descriptions form the initial catalog; full instructions are sent to the model only on activation. Unrelated or trivial requests need no skill. Reuse instructions already in context, and read references or run scripts only when the current step needs them. Type `/` in the chat composer to select one explicitly. User and agent skills take precedence over matching native defaults. MCP integrations may require credentials or tools installed in the job environment.

## Adding your own skills

Open **Settings → Skills, tools & plugins** to attach portable `SKILL.md` files to a reusable agent, or import a complete agent bundle for skills with supporting files. Select that agent in **New Job**. See [native skill integration details](docs/NATIVE_SKILLS.md).
